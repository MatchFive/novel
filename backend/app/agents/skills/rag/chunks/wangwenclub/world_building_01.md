## 力量体系设计

### 等级划分基本原则

- 清晰明了：命名有规律，读者容易理解，避免混乱。
- 数量适中：10-15级合适，太多会模糊，太少缺乏升级爽点。
- 梯度明显：级别间差距清晰，让读者感受到成长含金量。
- 递进合理：符合逻辑，避免跨度突兀，不能突然跨多个大境界。

### 常见模式

**玄幻修真体系**：炼气期 → 筑基期 → 金丹期 → 元婴期 → 化神期 → 合体期 → 大乘期 → 渡劫期 → 真仙 → 金仙 → 大罗金仙。

**武侠体系**：后天境 → 先天境 → 宗师境 → 大宗师 → 至尊境 → 破碎虚空。

**都市异能体系**：F → E → D → C → B → A → S → SS → SSS。

### 每个等级的设定

需要明确：晋级条件、实力表现、寿命变化、数量分布、社会地位。等级差距不仅体现在力量，还应体现在资源、权力和寿命。这样升级不只是数字变化，而是生活方式和地位的变化。

### 瓶颈设置

作用：增加难度、制造悬念、延长篇幅、提供爽点。类型包括境界瓶颈、心境瓶颈、资源瓶颈、天劫考验。瓶颈要合理，不能每次都靠运气突破，否则读者失去紧张感。

## 地理设定

- **空间层次**：小世界 → 中世界 → 大世界 → 仙界 → 神界。换地图不仅是空间变化，也是力量层次和社会规则的变化。
- **换地图时机**：主角在当前世界接近无敌或遇到天花板时，一般20-50万字一次。换地图要有充分动机，不能为了换而换。
- **特殊区域**：秘境/遗迹提供机缘，禁地/险地后期揭秘，城市/宗门是势力舞台。地图要和主角成长阶段相匹配。

## 社会结构

- **势力划分**：宗门、家族、散修、官方、商会。不同势力有各自利益和规则，主角与势力的关系变化是社会地位成长的核心。
- **权力层级**：宗主 → 长老 → 堂主 → 执事 → 弟子。层级明确便于制造冲突和地位成长，也清晰展示主角上升路径。
- **经济系统**：货币（灵石、仙晶）、丹药、功法、法宝、材料。经济系统是主角获取资源、交易和成长的重要驱动力。稀缺资源往往是最有力的冲突来源。

## 世界观一致性

- 规则要统一：同一体系下不能前后矛盾，力量上限和边界要明确。
- 信息要分层：前期给出基础规则，随着主角成长逐步揭秘深层设定。不要一次性抛出所有设定。
- 历史要有因果：重大事件、传说、遗迹都要有原因和影响，让世界有厚度。
- 文化要真实：语言、习俗、礼仪等细节能增强代入感。社会不可能只有打打杀杀，还需要日常规则。
- 常见坑：设定过于复杂开篇大量抛术语；力量体系崩坏后期战力失控；地图缺乏特色只是换名字；社会规则没有逻辑导致势力行为前后不一。
